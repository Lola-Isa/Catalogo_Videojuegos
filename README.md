# PROYECTO: Catálogo de videojuegos
Proyecto web creado con Astro, que permite al usuario explorar videojuegos mediante el buscador, filtrarlos por género y un modo oscuro para mayor comodidad

## Herramientas utilizadas

-Astro
-HTML
-CSS
-JavaScript

# Cómo se ejecuta el proyecto

1- Se clona el repositorio de Github:
git clone https://github.com/LolaDoming/Catalogo_Videojuegos.git

2- Instalar dependencias:
npm install

3- Ejecutar el proyecto:
npm run dev

4- Abrir el siguiente link en el navegador:
https://localhost:4321
